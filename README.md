# Himari Room (Japanese Version)🌻

The Japanese version of Himari Room, a Discord companion designed to offer gentle and natural conversations.

## Features

- English conversation on Discord
- Friendly responses
- JSON-based reply management
- Cloud-hosted on Railway

## Tech Stack

- Python
- discord.py
- Railway
- JSON

## Future Plans

- LLM-powered conversations
- Multi-character interactions
- Richer and more natural dialogue
- Broader conversation topics

## Status

This project is currently under active development ✨
